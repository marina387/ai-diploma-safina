

\## Статистические показатели в системе подбора персонала



| Показатель | Назначение | Устойчивость к выбросам |

|------------|------------|------------------------|

| \*\*mean\*\* (среднее) | Средний опыт, навыки, зарплата | Низкая |

| \*\*median\*\* (медиана) | Медианная зарплата, типичный опыт успешных кандидатов | \*\*Высокая\*\* |

| \*\*variance\*\* (дисперсия) | Разброс зарплат, разнородность опыта | Низкая |

| \*\*std\*\* (стандартное отклонение) | Оценка различий кандидатов для кластеризации и поиска аномалий | Низкая |





\## Распределения и гистограммы



| Код | Применение в боте |

|-----|-------------------|

| `np.random.normal()` | Создание тестовых эмбеддингов для отладки |

| `np.mean()`, `np.std()` | Нормализация векторов, анализ средних оценок кандидатов |

| `np.median()` | Устойчивая оценка при выбросах (например, зарплаты) |

| `plt.hist()` | Визуализация распределения схожести вакансий и резюме |

| `len()`, `isinstance()` | Проверка корректности входных данных от пользователя |

\## Вероятность, условная вероятность, независимость + симуляции



| Функция | Назначение в системе подбора персонала |

|---------|----------------------------------------|

| `prob\_event` | Расчет базовых вероятностей: доля подходящих кандидатов в базе, вероятность отклика, вероятность прохождения этапа отбора |

| `prob\_conditional` | Условные вероятности: P(оффер \\| знание Python), P(приглашение \\| опыт 3+ года), P(успех \\| наличие сертификата) |

| `is\_independent\_by\_counts` | Проверка независимости навыков от успеха найма — какие требования действительно важны, а какие можно убрать |

| `contingency\_4x4` | Анализ связей между категориальными признаками (образование × грейд, специализация × индустрия, источник × удержание) |

| `simulate\_click\_buy` | Генерация синтетических данных для тестирования алгоритмов ранжирования при недостатке реальных HR-данных |

| `estimate\_p\_buy\_given\_click1` | Оценка устойчивости модели ранжирования через многократные симуляции (Монте-Карло) |

| Визуализация (matplotlib) | Построение графиков распределения кандидатов, визуализация метрик ранжирования (Precision@K, NDCG) |
