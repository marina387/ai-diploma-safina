## Статистические показатели в системе подбора персонала

| Показатель | Назначение | Устойчивость к выбросам |
|------------|------------|------------------------|
| **mean** (среднее) | Средний опыт, навыки, зарплата | Низкая |
| **median** (медиана) | Медианная зарплата, типичный опыт успешных кандидатов | **Высокая** |
| **variance** (дисперсия) | Разброс зарплат, разнородность опыта | Низкая |
| **std** (стандартное отклонение) | Оценка различий кандидатов для кластеризации и поиска аномалий | Низкая |


## Распределения и гистограммы

| Код | Применение в боте |
|-----|-------------------|
| `np.random.normal()` | Создание тестовых эмбеддингов для отладки |
| `np.mean()`, `np.std()` | Нормализация векторов, анализ средних оценок кандидатов |
| `np.median()` | Устойчивая оценка при выбросах (например, зарплаты) |
| `plt.hist()` | Визуализация распределения схожести вакансий и резюме |
| `len()`, `isinstance()` | Проверка корректности входных данных от пользователя |

## Вероятность, условная вероятность, независимость + симуляции

| Функция | Назначение в системе подбора персонала |
|---------|----------------------------------------|
| `prob_event` | Расчет базовых вероятностей: доля подходящих кандидатов в базе, вероятность отклика, вероятность прохождения этапа отбора |
| `prob_conditional` | Условные вероятности: P(оффер \| знание Python), P(приглашение \| опыт 3+ года), P(успех \| наличие сертификата) |
| `is_independent_by_counts` | Проверка независимости навыков от успеха найма — какие требования действительно важны, а какие можно убрать |
| `contingency_4x4` | Анализ связей между категориальными признаками (образование × грейд, специализация × индустрия, источник × удержание) |
| `simulate_click_buy` | Генерация синтетических данных для тестирования алгоритмов ранжирования при недостатке реальных HR-данных |
| `estimate_p_buy_given_click1` | Оценка устойчивости модели ранжирования через многократные симуляции (Монте-Карло) |
| Визуализация (matplotlib) | Построение графиков распределения кандидатов, визуализация метрик ранжирования (Precision@K, NDCG) |



## 📊 Функции для вероятностного скоринга кандидатов

| Функция | Входные параметры | Выход | Назначение в системе подбора |
|---------|-------------------|-------|------------------------------|
| `build_binary_counts(recs, a_key, b_key)` | Список записей, название признака A, название признака B | Словарь с частотами: `n`, `count_A`, `count_B`, `count_A_and_B` | Подсчёт частот для анализа связи между навыками и успешным наймом |
| `prob_from_counts(count, n)` | Количество событий, общее число наблюдений | Вероятность (float) | Базовая вероятность наличия навыка или успеха |
| `prob_conditional(count_A_and_B, count_A)` | Количество пересечений, количество A | Условная вероятность P(B\|A) | Вероятность успеха при наличии навыка |
| `bayes_posterior(prior, likelihood, evidence)` | Априорная вероятность, правдоподобие, нормировка | Апостериорная вероятность P(A\|B) | Обновление вероятности успеха при появлении новой информации |
| `score_buy_probability(recs, clicked_value)` | Данные, значение признака (0/1) | Вероятность покупки | **Для HR:** вероятность успешного найма при наличии/отсутствии навыка |
| `laplace_smooth_prob(successes, trials)` | Количество успехов, количество попыток | Сглаженная вероятность | Учёт редких навыков (чтобы вероятность не обнулялась) |

| Функция | HR-кейс | Интерпретация для рекрутера |
|---------|---------|------------------------------|

| `prob_conditional` | P(успех \| есть Python) | Как часто кандидаты с Python реально проходят отбор |

| `laplace_smooth_prob` | Редкий навык (Rust, 2 кандидата) | Даже по двум кандидатам не зануляем вероятность |
| `score_buy_probability` | Оценка кандидата по одному критерию | Базовый блок для скоринг-карты |
