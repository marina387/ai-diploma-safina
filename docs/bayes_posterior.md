# Формула Байеса: теория и применение в дипломном проекте

## 📐 Формула Байеса: теория

### Что это такое?

Формула Байеса — это математический способ **обновлять вероятности** при появлении новой информации.

**Классическая формула:**

$$
P(A|B) = \frac{P(B|A) \times P(A)}{P(B)}
$$

text

### Что означают части формулы

| Обозначение      | Название                          | Смысл                                                                 |
|------------------|----------------------------------|----------------------------------------------------------------------|
| **P(A)**         | Априорная вероятность (prior)    | Наша уверенность ДО того, как мы увидели новую информацию            |
| **P(B|A)**       | Правдоподобие (likelihood)       | Насколько часто встречается признак B, если гипотеза A верна         |
| **P(B)**         | Нормировка (evidence)             | Как часто признак B встречается вообще                               |
| **P(A|B)**       | Апостериорная вероятность (posterior) | Обновлённая уверенность ПОСЛЕ того, как мы увидели признак B  |

### Интуитивное понимание

Формула Байеса отвечает на вопрос:

> "Как мне пересмотреть свою уверенность в гипотезе, если я получил новые данные?"

**Пример из жизни:**

- Вы думаете, что в городе 20% людей — программисты (P(A))
- Вы встретили человека с ноутбуком (признак B)
- Среди программистов 90% ходят с ноутбуками (P(B|A))
- В целом по городу 30% людей ходят с ноутбуками (P(B))

Вопрос: какова вероятность, что этот человек — программист?

**Решение:**

$$
P(A|B) = \frac{0.9 \times 0.2}{0.3} = 0.6 \ (60\%)
$$

text

Уверенность выросла с 20% до 60% благодаря наблюдению.

### Ключевые свойства

1. **Если признак редкий, но очень характерный** — уверенность растёт сильно  
2. **Если признак очень популярный** — он мало что добавляет  
3. **Если признаки независимы** — $P(A|B) = P(A)$

##  Связь с дипломным проектом

### Как мы применяем Байеса в подборе персонала

В нашей системе формула Байеса используется для **скоринга кандидатов** — оценки вероятности успешного найма с учётом наличия навыков.

**Соответствие компонентов:**

| Компонент формулы | Что в дипломе                                  |
|-------------------|-----------------------------------------------|
| **P(успех)**      | Базовая вероятность найма по истории компании |
| **P(навык \| успех)** | Среди успешных кандидатов — сколько владеют этим навыком |
| **P(навык)**      | Как часто навык встречается в базе кандидатов  |
| **P(успех \| навык)** | Итоговый скоринг кандидата (шансы на успех с учётом навыка) |

### Пример из реальных данных

```python
# Данные компании за прошлый год
total_candidates = 100       # всего кандидатов
successful = 30              # успешно нанятые
python_among_successful = 25 # среди успешных знали Python
python_total = 40            # всего кандидатов с Python

# Расчёт компонентов
p_success = successful / total_candidates                       # P(успех) = 0.3
p_python_given_success = python_among_successful / successful  # P(Python|успех) = 0.83
p_python = python_total / total_candidates                      # P(Python) = 0.4

# Байесовский скоринг
p_success_given_python = (p_python_given_success * p_success) / p_python
print(f"Базовая вероятность найма: {p_success:.1%}")
print(f"Вероятность найма при знании Python: {p_success_given_python:.1%}")
print(f"📈 Знание Python повышает шансы в {p_success_given_python/p_success:.1f} раз")


### Результат:

text  
Базовая вероятность найма: 30.0%  
Вероятность найма при знании Python: 62.5%  
📈 Знание Python повышает шансы в 2.1 раз

### Интерпретация для рекрутера

**Без формулы Байеса:**

> "Этот кандидат знает Python. Наверное, подходит."

**С формулой Байеса:**

> "Базовая вероятность успеха по компании — 30%.  
> Среди успешных кандидатов 83% знали Python.  
> В целом Python знают 40% кандидатов.  
> С учётом всех данных, вероятность успеха этого кандидата — 62.5%.  
> Знание Python повышает шансы в 2.1 раза."

### Почему это важно для диплома

- **Интерпретируемость** — рекрутер видит не просто цифру, а логику её получения  
- **Прозрачность** — можно объяснить, почему один кандидат получил 80%, а другой 30%  
- **Объективность** — оценки основаны на реальных данных, а не на интуиции  
- **Масштабируемость** — формула работает для любого количества признаков

### Визуализация результата
```
