## Анализ существующих систем подбора персонала

### 1.1. Эволюция подходов к автоматизации рекрутмента

Современные системы подбора прошли путь от простых фильтров по ключевым словам до сложных алгоритмов семантического анализа на базе нейросетей. Анализ решений 2024-2026 годов позволяет выделить три основных класса моделей.

### 1.2. Сравнительный анализ моделей

| Модель | Принцип работы | Достоинства | Недостатки |
|--------|----------------|--------------|------------|
| **Лексические модели (TF-IDF, BM25)** | Анализ частоты ключевых слов, точное совпадение терминов | • Высокая скорость работы<br>• Простота реализации<br>• Интерпретируемость результатов<br>• Эффективность для формальных навыков | • Низкая корреляция с экспертной оценкой<br>• Игнорирование контекста и синонимии<br>• Не работают с soft skills<br>• Чувствительность к опечаткам |
| **Модели на эмбеддингах (Sentence-BERT, MPNet)** | Преобразование текста в векторные представления, поиск по семантической близости | • Глубокое понимание контекста<br>• Устойчивость к шуму и опечаткам<br>• Линейная скорость при масштабировании (FAISS)<br>• Работа с разными формулировками | • Высокие требования к ресурсам<br>• Риск воспроизведения предубеждений<br>• Отсутствие объяснимости решений<br>• Склонность предпочитать длинные резюме |
| **Большие языковые модели (LLM)** | Полноценный семантический анализ с элементами рассуждения | • Наивысшая корреляция с экспертами<br>• Выявление скрытых соответствий<br>• Генерация объяснений<br>• Гибкость настройки через промпты | • Высокая стоимость и низкая скорость<br>• Чувствительность к качеству промптов<br>• Риск галлюцинаций<br>• Требовательность к квалификации |

### 1.3. Ключевые выводы

1. **Оптимальная архитектура** — гибридная: быстрый предотбор на эмбеддингах + детальный анализ LLM для топ-кандидатов
2. **Главные нерешенные проблемы:**
   - Отсутствие интерпретируемости решений ("черный ящик")
   - Воспроизведение алгоритмической предвзятости
   - Фокус только на найме без прогнозирования удержания
   - Поверхностный анализ навыков без контекста применения
   - Ограниченность источников формальными базами резюме

## 2. Концептуальная новизна предлагаемого решения

### 2.1. Выявленные "белые пятна" рынка HR-tech

| Проблема | Описание |
|----------|----------|
| **Доверие к ИИ** | Системы не объясняют решения → рекрутер либо слепо доверяет, либо перепроверяет вручную |
| **Прогноз удержания** | Оценка "здесь и сейчас" без анализа совместимости с командой и вероятного срока работы |
| **Источники поиска** | Игнорирование активных профессиональных сообществ (Telegram, профильные форумы) |
| **Контекст навыков** | Поверхностный учет ключевых слов без анализа реального уровня владения |

### 2.2. Ключевая инновация: интерпретируемый ИИ с визуальными скоринг-картами

**Суть:** Система предоставляет не интегральную оценку, а детализированный разбор по ключевым категориям с цветовой кодировкой.

**Визуальная форма представления:**
- 🟩 **Зеленые блоки** — полное соответствие требованиям
- 🟨 **Желтые блоки** — частичное соответствие (смежный опыт)
- 🟥 **Красные блоки** — критичные расхождения или отсутствие компетенций

**Пример скоринг-карты:**

| Категория | Оценка | Статус |
|-----------|--------|--------|
| Технические навыки (Python, SQL, ML) | 🟩 | Полное соответствие |
| Управленческий опыт (team lead) | 🟨 | Частичное соответствие |
| Soft skills (коммуникация, адаптивность) | 🟩 | Полное соответствие |
| Образование (профильное/сертификаты) | 🟥 | Критичное расхождение |
| Ожидания по зарплате | 🟨 | Частичное соответствие |
| **Итоговая рекомендация** | 🟨 | **ПРИГЛАСИТЬ УСЛОВНО** |


### 2.3. Преимущества предлагаемого подхода

| Преимущество | Описание |
|--------------|----------|
| **Преодоление недоверия к ИИ** | Прозрачность решений повышает готовность использовать систему как помощника |
| **Экономия времени** | Визуальное представление → решение о приглашении за секунды, а не минуты |
| **Обучающий эффект** | Помогает молодым рекрутерам понимать значимые аспекты резюме |
| **Этичность и explainability** | Соответствие трендам 2026 года (внимание к объяснимому ИИ) |

### 2.4. Дополнительные возможности (опционально)

🔮 **Предиктор удержания** — оценка вероятности работы в компании >1 года на основе исторических паттернов

📊 **Контекстный анализ навыков** — оценка не просто наличия ключевых слов, а уровня владения с учетом контекста

🤝 **Двусторонний матчинг** — подбор вакансий под кандидата с прогнозом карьерной траектории
