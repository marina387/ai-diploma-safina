### `salary_stats.py` — Анализ зарплат кандидатов

Модуль для расчета и анализа зарплатных ожиданий кандидатов.

**Функции:**

| Функция | Описание |
|---------|----------|
| `mean(values)` | Средняя зарплата (чувствительна к выбросам) |
| `median(values)` | Медианная зарплата (устойчива к выбросам) |
| `variance_sample(values)` | Разброс зарплатных ожиданий |
| `std_sample(values)` | Стандартное отклонение (для поиска аномалий) |
| `trimmed_mean(values, k)` | Среднее без учета выбросов |

**Пример использования:**
```python
salaries = [120, 150, 110, 180, 250, 130, 140, 600, 135, 125]
print(f"Медианная зарплата: {median(salaries)}")
print(f"Среднее без выбросов: {trimmed_mean(salaries, k=1)}")


### `stats_demo.py` — Демонстрация статистики

Демонстрационный скрипт, показывающий применение статистики в HR-контексте.

**Что делает:**
- Генерирует тестовые эмбеддинги кандидатов
- Анализирует распределение кандидатов в семантическом пространстве
- Считает статистики (среднее, медиана, стандартное отклонение)
- Ищет аномальных кандидатов
- Строит гистограммы распределения и схожести с вакансией

**Пример генерации эмбеддингов:**


import numpy as np
import matplotlib.pyplot as plt

# Генерируем 1000 тестовых эмбеддингов (нормальное распределение)
embeddings = np.random.normal(0, 1, 1000)
print(f"Сгенерировано {len(embeddings)} тестовых эмбеддингов")

# Считаем статистики
mean_val = np.mean(embeddings)
std_val = np.std(embeddings)
median_val = np.median(embeddings)

print(f"Среднее: {mean_val:.3f}")
print(f"Стандартное отклонение: {std_val:.3f}")
print(f"Медиана: {median_val:.3f}")

# Ищем аномалии (отклонение > 3 сигм)
anomalies = embeddings[np.abs(embeddings - mean_val) > 3 * std_val]
print(f"Найдено аномалий: {len(anomalies)}")

# Строим гистограмму
plt.hist(embeddings, bins=30)
plt.title("Распределение тестовых эмбеддингов")
plt.show()
